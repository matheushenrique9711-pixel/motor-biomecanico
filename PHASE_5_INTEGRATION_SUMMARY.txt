INTEGRATION WORKFLOW
================================================================================

Complete Case Lifecycle with Database Integration:

1. CREATE CASE
   POST /cases/ → Create Patient + ClinicalCase
   Response: case_id, patient_info, status=CREATED

2. ANALYZE
   POST /cases/{case_id}/analyze → Store biomechanical_profile
   Response: status=ANALYZED, analysis_confidence

3. GENERATE SUGGESTIONS
   POST /cases/{case_id}/suggestions → AI analysis + store suggestions
   Response: suggestions list, primary_condition

4. CONFIRM SUGGESTIONS
   POST /cases/{case_id}/confirm-suggestions → status=SUGGESTIONS_REVIEWED
   Response: confirmation, clinician notes recorded

5. APPLY ADJUSTMENTS
   POST /cases/{case_id}/apply-adjustments → Store parameters + audit trail
   Response: status=ADJUSTMENTS_CONFIRMED, adjustment history recorded

6. GENERATE GEOMETRY
   POST /cases/{case_id}/generate-geometry → 3D model + STL export
   Response: STL file path, dimensions, status=GEOMETRY_GENERATED

7. EXPORT STL
   POST /cases/{case_id}/export-stl → File ready for printing
   Response: filename, size, download info, status=EXPORTED

8. ADD FEEDBACK
   POST /cases/{case_id}/feedback → Clinical results recorded
   Response: feedback stored, status=FEEDBACK_COLLECTED

All operations:
- Persist data to PostgreSQL
- Maintain referential integrity via foreign keys
- Record audit trail in AdjustmentHistory
- Support rollback on errors
