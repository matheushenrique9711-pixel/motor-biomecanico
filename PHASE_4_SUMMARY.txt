================================================================================
USAGE EXAMPLES
================================================================================

Importing Database Layer:
```python
from app.database import (
    get_db,
    ClinicalCaseRepository,
    PatientRepository,
)
```

Creating Route with Database:
```python
from fastapi import APIRouter, Depends
from sqlalchemy.orm import Session

@router.get("/cases/{case_id}")
async def get_case(case_id: str, db: Session = Depends(get_db)):
    case = ClinicalCaseRepository.get_by_case_id(db, case_id)
    if not case:
        raise HTTPException(status_code=404, detail="Not found")
    return case
```

Creating Clinical Data:
```python
# Create patient
patient = PatientRepository.create(
    db, "PAT-001", "João Silva", 45, "M", "Dor nos pés"
)

# Create case
case = ClinicalCaseRepository.create(
    db, "CASE-001", patient.id
)

# Add analysis
ClinicalCaseRepository.update_biomechanical_analysis(
    db, "CASE-001",
    {"foot_length": 265.0, "arch_index": 0.18},
    0.92
)
```
